# Create-WinISO

## Scripts
- `Create-WinISO.ps1`: Build a customized Windows Pro ISO with injected drivers.

## Usage
Run in PowerShell with the required permissions and dependencies.

## Script Notes
### `Create-WinISO.ps1`
- Synopsis: Build a customized Windows Pro ISO with injected drivers.
- Description: Copies a user-selected ISO into StockISO, extracts it, automatically detects the Windows Pro index, injects drivers, and rebuilds a BIOS+UEFI bootable ISO.
