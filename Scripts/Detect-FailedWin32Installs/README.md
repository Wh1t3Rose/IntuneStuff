# Detect-FailedWin32Installs

## Scripts
- `Detect-FailedWin32Installs.ps1`: DETECTTION SCRIPT Detects failed Win32 app installations from Intune.

## Usage
Run in PowerShell with the required permissions and dependencies.

## Script Notes
### `Detect-FailedWin32Installs.ps1`
- Synopsis: DETECTTION SCRIPT Detects failed Win32 app installations from Intune.
- Description: This script identifies failed Win32 app installations from Intune by searching the registry. It returns a list of failed app installations.
